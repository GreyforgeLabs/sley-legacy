# Changelog

## 0.1.0 - 2026-08-28

- Replace mutating GET execution with Origin- and CSRF-protected JSON POST.
- Default to loopback/read-only operation with explicit remote and mutation gates.
- Confine real targets and static assets after symlink resolution.
- Add asynchronous timeout, output-cap, cancellation, and process-group teardown.
- Add strict CLI parsing, package-sourced versioning, and HTTP regression tests.

## 0.0.0-private - 2026-05-06

- Initial private scaffold for `sley-workbench`.
- Added documentation, brand assets, examples, and smoke-test entry points.

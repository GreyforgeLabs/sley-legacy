# Sley post-GA plan

Status: deferred work after the 1.2 release candidate
Updated: 2026-08-26

The 1.2 evidence supports one bounded reference workload and one controlled
agent workflow. It does not support broad production adoption. Post-GA work
must keep negative results, incumbent oracles, and exact approval boundaries.

## Ordered follow-up

1. Inventory Greyforge candidates with the Sley First affinity model and record
   use, pilot, retain, or prohibit decisions.
2. Repeat the controlled agent workflow enough times to estimate variance;
   separate structural-context cost from correctness or review benefit.
3. Add production-like shadow evidence only for separately approved candidates,
   with latency, fallback, rollback, and operator-review measurements.
4. Rehearse standalone extraction without changing the 1.2 archive's supported
   platform claim.
5. Evaluate macOS, Windows, container, signature, package-manager, and public
   hosting channels independently. Do not imply support before each channel has
   its own clean-install and security evidence.
6. Consider translators, HTTP tenancy, external adapters, additional language
   constructs, Wasm, training/corpus expansion, and semantic merge as separate
   1.3 or beta packages.

Promotion remains a recorded decision, not an automatic consequence of a
passing replay, benchmark, release build, or public artifact.

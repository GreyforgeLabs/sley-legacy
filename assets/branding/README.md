# Sley Branding Assets

Status date: 2026-05-06.

These are Sley project branding assets. The ForgeVideo review app was used only
as a local review UI; these files have nothing to do with ForgeVideo production,
Drawn_To_Empire canon, episode assets, or provider-routing gates.

## Canonical Theme

Canonical visual direction: `Loom Graph`.

Use this theme for Sley public-facing concept work unless a later branding
review supersedes it. The operator review approved the theme for simplicity and
fit with Sley's structural-language identity.

Visual rules:

- deep ink base with off-white typography
- emerald and cobalt graph/loom lines
- small polished silver accents
- typed graph, loom, source-projection, and verified-structure motifs
- no purple-dominant gradients, beige/brown palette, generic cyberpunk, fake
  code screenshots, mascots, or watermarks
